CROSS-PLATFORM SUPPORT
======================

CRITICAL: Three independent implementations with IDENTICAL functionality.
All produce the same results. Choose based on your environment.

THREE IMPLEMENTATIONS
---------------------
Orchestrator    Language      Best For
debee.ps1       PowerShell    Windows, teams using PowerShell
debee.sh        Bash          Linux/macOS native, CI/CD pipelines
debee.py        Python        Cross-platform consistency, Python teams

WHICH TO CHOOSE
---------------
Windows         → debee.ps1 (native) or debee.py
Linux/macOS     → debee.sh (native) or debee.py
Mixed envs      → debee.py for consistency
CI/CD           → debee.sh (lightweight) or debee.py

PLATFORM COMPATIBILITY
----------------------
Orchestrator    Windows    Linux          macOS          WSL
debee.ps1       Native     PS Core req.   PS Core req.   PS Core req.
debee.sh        WSL only   Native         Native         Native
debee.py        Native     Native         Native         Native

Runtime Requirements:
  debee.ps1     PowerShell 5.1+ (Windows) or PowerShell Core 6.0+
  debee.sh      Bash 4.0+
  debee.py      Python 3.6+

All also require: psql, pg_restore, Python 3.6+ (for extract-db-objects.py)

CLI REFERENCE — POWERSHELL (debee.ps1)
--------------------------------------
.\debee.ps1
  -Operations <string[]>        # Operations to run (omit -> show help)
  [-Environment <string>]       # Environment name for config file
  [-UpdateStartNumber <int>]    # First migration number (default: env or -1 = all)
  [-UpdateEndNumber <int>]      # Last migration number (default: env or -1 = all)
  [-SqlFile <string>]           # SQL file for execSql
  [-Sql <string>]               # Inline SQL for execSql
  [-TestFilter <string>]        # Test filter for runTests (default: "all")
  [-TestVerbose]                # Show all test output including PASS lines
  [-Silent] [-q]                # Suppress orchestration messages
  [-Yes] [-y]                   # Skip the production confirmation prompt
  [-Version] [-V]               # Print version and exit
  [-Help] [-h] [-?]             # Show help and exit
  [-Llm]                        # Print full CLI reference for LLM/AI assistants

NOTE: debee.ps1 has NO default operation — running it with no -Operations
prints the help screen. debee.sh and debee.py default to fullService.

Examples:
  .\debee.ps1 -Operations fullService
  .\debee.ps1 -Operations updateDatabase -UpdateStartNumber 10 -UpdateEndNumber 20
  .\debee.ps1 -Operations @("restoreDatabase", "updateDatabase")
  .\debee.ps1 -Operations execSql -SqlFile path/to/script.sql
  .\debee.ps1 -Operations execSql -Sql "SELECT version();"
  .\debee.ps1 -Operations runTests -TestFilter connectivity
  .\debee.ps1 -Environment staging -Operations updateDatabase

CLI REFERENCE — BASH (debee.sh)
-------------------------------
./debee.sh [options]
  -o, --operations <ops>      # Comma-separated operations (default: fullService)
  -e, --environment <env>     # Environment name for config file
  -s, --start-number <num>    # First migration number (default: env or -1 = all)
  -n, --end-number <num>      # Last migration number (default: env or -1 = all)
      --sql-file <file>       # SQL file for execSql
      --sql <query>           # Inline SQL for execSql
      --test-filter <pattern> # Test filter for runTests (default: "all")
      --test-verbose          # Show all test output including PASS lines
  -q, --silent                # Suppress orchestration messages
  -y, --yes                   # Skip the production confirmation prompt
  -V, --version               # Print version and exit
  -h, --help                  # Show help
      --llm                   # Print full CLI reference for LLM/AI assistants

Examples:
  ./debee.sh -o fullService
  ./debee.sh -o updateDatabase -s 10 -n 20
  ./debee.sh -o restoreDatabase,updateDatabase
  ./debee.sh -o execSql --sql-file path/to/script.sql
  ./debee.sh -o execSql --sql "SELECT version();"
  ./debee.sh -o runTests --test-filter connectivity
  ./debee.sh -e staging -o updateDatabase

CLI REFERENCE — PYTHON (debee.py)
---------------------------------
python debee.py [options]
  -o, --operations <ops>      # Comma-separated operations (default: fullService)
  -e, --environment <env>     # Environment name for config file
  -s, --start-number <num>    # First migration number (default: env or -1 = all)
  -n, --end-number <num>      # Last migration number (default: env or -1 = all)
      --sql-file <file>       # SQL file for execSql
      --sql <query>           # Inline SQL for execSql
      --test-filter <pattern> # Test filter for runTests (default: "all")
      --test-verbose          # Show all test output including PASS lines
  -q, --silent                # Suppress orchestration messages
  -y, --yes                   # Skip the production confirmation prompt
  -V, --version               # Print version and exit
      --no-color              # Disable colored output (for CI/CD)
      --llm                   # Print full CLI reference for LLM/AI assistants

Examples:
  python debee.py -o fullService
  python debee.py -o updateDatabase -s 10 -n 20
  python debee.py -o restoreDatabase,updateDatabase
  python debee.py -o execSql --sql-file path/to/script.sql
  python debee.py -o execSql --sql "SELECT version();"
  python debee.py -o runTests --test-filter connectivity
  python debee.py -e staging -o updateDatabase
  python debee.py -o updateDatabase --no-color

UTILITY FLAGS (IDENTICAL ACROSS ALL THREE)
------------------------------------------
sh/py             ps1                 Purpose
-q, --silent      -Silent, -q         Suppress orchestration messages (errors/psql output remain)
-y, --yes         -Yes, -y            Skip DBPRODENVIRONMENT confirmation prompt (CI/automation)
--test-verbose    -TestVerbose        Show all test output including PASS lines
-V, --version     -Version, -V        Print version (1.1.1) and exit
-h, --help        -Help, -h, -?       Show help and exit
--llm             -Llm                Print self-contained CLI reference for LLM/AI assistants

The --llm output is byte-for-byte identical across debee.ps1, debee.sh, debee.py.

IMPLEMENTATION DIFFERENCES
--------------------------
Feature                 ps1                    sh                 py
Multiple ops syntax     Array: @("a","b")      Comma: a,b         Comma: a,b
Color output            PowerShell colors      ANSI escapes       ANSI + TTY detect
Disable colors          —                      —                  --no-color flag
JSON parsing            ConvertFrom-Json       python3 -c         json module
Env inheritance         Automatic              Automatic          Explicit env=os.environ
